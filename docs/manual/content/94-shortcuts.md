# Keyboard shortcuts {: .appendix }

| Keys | Action |
|---|---|
| `Ctrl K` or `Cmd K` | Open search. |
| `/` | Open search when you are not typing in a field. |
| Up and Down | Move in search results and menus. |
| Enter | Open the highlighted result. |
| Esc | Close a dialog or search. |
| Tab and Shift Tab | Move between controls. |
| Left and Right | Switch tabs. |
| Space or Enter | Open or pick up a calendar bar (then move it with the arrow keys). |

The same list is on the **Account** page. A "Skip to content" link appears when you press Tab on any page. All screens are usable with the keyboard alone and meet WCAG 2.2 AA contrast and target-size rules.
