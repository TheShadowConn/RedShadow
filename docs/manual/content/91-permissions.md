# Permission matrix {: .appendix }

Every permission in RedShadow with the roles that hold it by default. **Platform** permissions apply everywhere. **Engagement** permissions apply on the engagements a person can reach (their team memberships, or all engagements for roles that reach every engagement). The table is generated from the application's catalogue when this manual is built, so it always matches the software.

[[PERMISSIONS]]

Administrators can change what a role holds. Super Admin always holds every permission.
