    Install

    Run it with one command.

    Docker Compose starts the database, Redis, workers and the web app. Migrations run on their own, and your data stays in named volumes.

    ~/RedShadow
    
          
    git clone https://github.com/TheShadowConn/RedShadow.git
cd RedShadow
docker compose up --build -d --wait
docker compose logs migrate | grep -A3 "FIRST LOGIN"
