Access control and audit log

Permissions are enforced by the server, and every change is recorded.

  1. Server-side permissions. Roles and per-engagement scope are enforced by the API, not the screen.
  2. Hash-chained audit log. Append-only entries with a built-in integrity check.
  3. Two-step sign-in. TOTP required by role, Argon2 passwords and lockout.

Install RedShadow

One command starts Docker Compose with PostgreSQL and Redis included.

Terminal
$ git clone https://github.com/TheShadowConn/RedShadow.git
$ cd RedShadow
$ docker compose up --build -d --wait
$ docker compose logs migrate | grep -A3 "FIRST LOGIN"
# the first admin password is printed once
# then open https://localhost and sign in
  1. Clone and start. Migrations run on their own and your data stays in named volumes.
  2. Sign in. Use the one-time admin password, then set your own and enrol two-step sign-in.
