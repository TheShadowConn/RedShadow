# Code of conduct

We want RedShadow to be a place where people can contribute without harassment.

- Be respectful. Criticise ideas and code, never people.
- No harassment, discrimination, personal attacks, doxxing or sexual language.
- Assume good intent, ask when something is unclear, and accept that maintainers make the final call.
- Security research must stay within the rules in `SECURITY.md`. Never test against systems you do not own.

Maintainers may edit or remove comments, issues and pull requests that break these rules, and may block repeat offenders. To report a problem, contact the maintainer through https://github.com/TheShadowConn.
